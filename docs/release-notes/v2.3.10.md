# v2.3.10

本版本将 Android App 的脚本执行环境重构为内置 Alpine Linux 沙盒，统一任务执行、依赖管理、日志输入和状态显示能力。

## Linux 沙盒

- APK 内置 Alpine minirootfs、PRoot 和 Android 兼容 loader，首次启动自动完成沙盒初始化。
- 内置 Python 3、pip、Node.js、npm、Bash、Go、Git、curl 与 coreutils。
- Alpine APK 默认使用 Huawei 镜像，pip 默认使用 Alibaba 镜像，npm 默认使用 npmmirror。
- 面板数据、脚本、日志和临时目录通过 PRoot bind mount 映射到沙盒。

## 任务与日志

- Python、Node.js、TypeScript、Bash、Go 和依赖命令统一进入 Linux 沙盒执行。
- 实时日志、历史日志和依赖安装日志支持 `\r`、`\n`、`\r\n` 终端输出边界。
- 排队和运行状态持续轮询，活动任务禁止重复启动，并支持停止整个 PRoot 进程组。
- Android 首次启动显示真实沙盒安装阶段、后端启动状态和具体失败原因。

## 依赖管理

- 手动安装、自动安装、卸载、重装、备份恢复和启动校验统一进入沙盒。
- Node.js 依赖统一保存到 `/panel/data/deps/nodejs`，任务自动注入 `NODE_PATH` 和可执行目录。
- Linux 软件包统一使用 Alpine APK 管理。
- Android App 依赖页显示 Linux 沙盒健康与版本信息，核心解释器由应用统一保护。

## 健康检查

- 系统健康页新增 Linux 沙盒运行时检查。
- 检查 Alpine、APK、Shell、Python、pip、Node.js、npm、Bash、Go 和 Git。

## 验证

- Go service 与 handler 编译检查通过。
- 沙盒命令、路径映射、镜像环境和依赖日志专项测试通过。
- Android Kotlin Debug 编译通过。
